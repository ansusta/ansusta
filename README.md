## 🗂️ Mes projets

### 01 · MatchTalent
**Plateforme de recrutement avec matching intelligent**

Une application full-stack qui rapproche candidats et recruteurs grâce à un système de recommandation comparant les CV aux offres d'emploi. Elle intègre également un module d'IA pour vérifier les documents des entreprises.

`React` `Node.js` `Express.js` `MongoDB` `FastAPI`

### 02 · NEXUS
**Marketplace avec prévisions de ventes**

Une marketplace multi-vendeurs de produits informatiques intégrant des modèles prédictifs pour anticiper le chiffre d'affaires et la demande par produit, et ainsi prévenir les ruptures de stock.

`React` `TypeScript` `Node.js` `PostgreSQL` `Machine Learning`

### 03 · Détection de fausses informations
**Classification de textes et traitement distribué**

Un pipeline de classification combinant traitement distribué de données, réseau de neurones séquentiel et optimisation automatique des hyperparamètres par algorithme génétique.

Résultat obtenu : **97,6 % de précision.**

`Python` `PySpark` `Deep Learning` `Flask`

### 04 · DocLick
**Application de prise de rendez-vous médicaux**

Une application web et Android permettant de réserver des créneaux médicaux à partir d'une base de code commune.

`Capacitor` `Node.js` `Express.js` `MySQL`

### 05 · Gestion d'une agence de voyages
**Application de bureau en Java**

Une application permettant de gérer les clients, les voyages et les réservations avec une base de données relationnelle.

`Java` `SQL`
